1. EXECUTIVE COMPLIANCE, ZERO-COPYLEFT & RUNASINVOKER GUARANTEE
--------------------------------------------------------------------------------

clip-storyboard-director is engineered under strict architectural and governance
invariants: 100% Local-First, Zero-Egress by default, and unprivileged user-mode
execution (RunAsInvoker). All storyboard creation, shot sequencing, 4D persistence
buffer tracking, Edge Chrome DevTools Protocol (CDP) bridge automation, downloads
watching, clue-frame optical extraction, and FFmpeg multi-track audio assembly
execute within local workstation process boundaries without requiring elevated
administrative privileges.

Runtime Dependencies Isolation & Boundary:
All direct Python runtime dependencies utilized in clip-storyboard-director are
distributed under permissive open-source licenses (MIT, Apache-2.0, PSFL):
- PyYAML (MIT)
- websocket-client (Apache-2.0)
- requests (Apache-2.0)
- Python Standard Library (PSFL-2.0)

Subprocess Boundary for edge-tts (GPL-3.0):
edge-tts is licensed under GPL-3.0. clip-storyboard-director invokes edge-tts
strictly via standard, unprivileged external subprocess calls or optional wrapper
interfaces. The core directorial engine, 4D persistence buffer, timeline cockpit,
and video assembly pipelines remain 100% MIT-licensed with zero copyleft linkage.
Users and organizations are free to substitute or swap alternative local speech
synthesis engines without modifying core architecture.

Subprocess Boundary for FFmpeg / FFprobe (LGPL-2.1+ / GPL-2.0+):
FFmpeg and FFprobe are executed exclusively as external system CLI subprocesses
(via subprocess.run) across standard OS PATHs with parameterized argument arrays.
No C/C++ libraries are statically or dynamically linked into Python binaries.

RunAsInvoker Non-Elevation Certification:
clip-storyboard-director operates strictly in standard unprivileged user space.
It requires zero administrative elevation (UAC prompt), zero root privileges,
and zero background daemon registrations.

Zero-Egress Perimeter:
The directorial server binds exclusively to localhost loopback (127.0.0.1:8765),
and CDP communication connects strictly to localhost (127.0.0.1:9222). Zero
telemetry, analytics, tracking, or media assets are transmitted over external
network interfaces.
