1. TARGET PERSONAS & AUDIENCE PROFILES
================================================================================

Persona 1: AI Filmmakers & Narrative Directors (Independent & Studio Creators)
- Role: Film directors, cinematographers, narrative writers, creative AI producers.
- Pain Points: Incoherent characters across generated shots, face and costume drift between cuts, manual tedious frame extraction and re-uploading, lack of continuous narrative timeline.
- Solution & Value Proposition: Declarative 4D Persistence Buffer (`project.yaml`) enforcing character, location, and prop continuity; automatic clue-frame chaining (shot N tail frame primes shot N+1); dual-pane Edge cockpit for seamless timeline and prompt steering.
- Primary Workflow: `clip-director init`, define persistence buffer, launch dual-pane cockpit (`clip-director cockpit`), orchestrate Veo/Kling/Runway takes, assemble rough-cut master with ducked dialogue (`clip-director assemble`).

Persona 2: Generative Media Engineers & Video Automation Developers
- Role: Pipeline engineers, MLOps specialists, creative tool builders, technical directors.
- Pain Points: Closed SaaS video portals requiring constant manual browser clicking; lack of local, scriptable CDP browser automation; desynchronized audio and video assets.
- Solution & Value Proposition: Chrome DevTools Protocol (CDP) bridge on port 9222 for headless/guided prompt injection; automatic downloads watcher with file hashing; declarative JSON/YAML schemas; zero cloud vendor lock-in.
- Primary Workflow: Scripted project generation via Python API (`StoryboardProject`), programmatic trigger of Edge CDP generation loops, automated ingest and multi-track audio stitch.

Persona 3: Content Creators, YouTubers & Multimedia Storytellers
- Role: Digital video producers, educators, documentary creators, social media storytellers.
- Pain Points: Complex NLE video editing suites (Premiere, DaVinci) are overkill for rapid prototyping of AI video ideas; synthesizing and syncing voiceovers with background music takes hours.
- Solution & Value Proposition: Integrated high-fidelity speech synthesis (`edge-tts`), automated side-chain audio ducking (dialogue over ambient beds), instant interactive HTML storyboard dashboard (`board_server.py`), one-command full render.
- Primary Workflow: Draft scene scripts, synthesize voice directives (`clip-director voice`), preview storyboard in browser, assemble complete film in minutes (`clip-director assemble`).

Persona 4: Autonomous Coding Agents & Agentic Media Frameworks
- Role: AI agents (Gemini/Antigravity, Claude Desktop, OpenAI Codex), autonomous bot workers.
- Pain Points: Cloud-locked generative platforms require OAuth/API keys and credit cards; CLI tools that leak credentials or require interactive root elevation break agentic execution.
- Solution & Value Proposition: 100% Local-first & zero-egress (`INV-LOCAL-01`), unprivileged user execution (`INV-UNPRIV-02`), machine-readable `llms.txt` and `ellmos-module.v2.json`, deterministic CLI exit codes and error logs.
- Primary Workflow: Headless CLI automation via `clip-director auto`, automated health audits via `clip-director doctor`, inspection via `llms.txt`.

4. GOVERNANCE & RUNTIME INVARIANTS
================================================================================

- INV-LOCAL-01: 100% Local-First & Zero-Egress (operates entirely offline on localhost; zero external cloud tracking or telemetry).
- INV-UNPRIV-02: Non-Elevation / RunAsInvoker (operates strictly within standard user permissions without administrative elevation).
- INV-LOOPBACK-03: Loopback IPC Isolation (local HTTP dashboard and CDP socket communicate exclusively on 127.0.0.1).
- INV-SANDBOX-04: Subprocess Sandboxing (FFmpeg, FFprobe, and edge-tts execute in isolated subprocesses with strict argument validation).
- INV-CONTINUITY-05: 4D Persistence Continuity (characters, locations, objects, and props are bound across space and time via project.yaml).
- INV-CLUEFRAME-06: Clue-Frame Optical Chaining (the final rendered frame of shot N automatically seeds the reference prompt of shot N+1).
- INV-STANDALONE-07: Standalone Production Guarantee (full end-to-end media production operates without requiring external suite packages).
- INV-MULTIOS-08: Multi-OS Cross-Platform Parity (verified deterministic operation across Windows, Linux, and macOS).
- INV-SYNC-09: Cloud-Sync & Mutex Resilience (hardened against OneDrive/Dropbox file collisions, lock contention, and transient copies).
- INV-SLA-10: 48h Security Response & 5-Day Triage SLA (dedicated vulnerability response protocol and formal triage commitment).
